## 344. Reverse String[cite: 1]

Write a function that reverses a string. The input string is given as an array of characters `s`[cite: 1].

You must do this by modifying the input array in-place with `O(1)` extra memory[cite: 1].

**Example 1:**[cite: 1]

* **Input:** `s = ["h","e","l","l","o"]`[cite: 1]
* **Output:** `["o","l","l","e","h"]`[cite: 1]

**Example 2:**[cite: 1]

* **Input:** `s = ["H","a","n","n","a","h"]`[cite: 1]
* **Output:** `["h","a","n","n","a","H"]`[cite: 1]

**Constraints:**[cite: 1]

* `1 <= s.length <= 10^5`[cite: 1]
* `s[i]` is a printable ascii character[cite: 1].
